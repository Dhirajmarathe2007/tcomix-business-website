# ☕ TCOMIX – Business Website

A modern, responsive business website for **TCOMIX**, a fictional Tea & Coffee Premix manufacturer. This project was built as a portfolio project to demonstrate production-quality frontend development using HTML, CSS, and JavaScript.

## 🌐 Live Demo

https://dhirajmarathe2007.github.io/tcomix-business-website/

---

## 📖 Overview

TCOMIX is a responsive multi-page business website designed for a tea and coffee premix company. It focuses on clean UI, accessibility, responsive layouts, and production-ready frontend practices.

The project showcases how a corporate website can present products, company information, and contact details with a professional user experience across desktop, tablet, and mobile devices.
